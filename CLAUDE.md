# CLAUDE.md

«С листа» — тренажёр чтения нот для пианиста. Показывает ноты на стане, слушает пианино через микрофон (или MIDI) и проверяет сыгранное. Статическое одностраничное приложение на чистом JS. Сайт: https://seliverstov-maxim.github.io/s-lista/ (GitHub Pages из корня `main`).

## Команды

```bash
npm run build      # src/ → index.html (обязательно после любых правок в src/)
npm test           # тесты распознавания звука, ~12 с, без зависимостей
npm install && npx playwright install chromium   # один раз, для e2e
npm run test:e2e   # Chromium: интерфейс, MIDI-заглушка, калибровка с искусственным микрофоном
npm run serve      # http://localhost:8080 — микрофон работает на localhost
```

## Где что лежит

- `src/app.html` — разметка, стили и вся логика интерфейса в одной IIFE. Разделы помечены `/* ---------- Название ---------- */`. Карта разделов — в `docs/architecture.md`, раздел 2.
- `src/detector.js` — распознавание: YIN, БПФ, `harmonicPick`, класс `PitchListener`. Не зависит от DOM, тестируется в Node.
- `src/glyphs.json` — контуры нотных знаков Bravura (SMuFL), в межстрочных интервалах. Генерируется `scripts/extract-glyphs.py`.
- `index.html` — **сгенерированный** файл, но хранится в git: его раздаёт Pages. Руками не править.
- `docs/` — требования (FR/NFR/критерии приёмки), архитектура, решения (ADR), тестирование, бэклог.
- `tests/detector.test.mjs` — тесты распознавания, `tests/helpers/synth.mjs` — синтез фортепиано и шума, `tests/helpers/load-detector.mjs` — загрузка детектора в Node, `tests/e2e/run.mjs` — Playwright.

## Порядок работы

1. Перед задачей прочитайте нужный раздел `docs/architecture.md` и связанные требования в `docs/requirements.md`.
2. Правьте только `src/`, `scripts/`, `tests/`, `docs/`.
3. `npm run build && npm test`. Если трогали интерфейс, калибровку или MIDI, ещё `npm run test:e2e` и посмотрите скриншоты в `tests/e2e/out/`.
4. Если изменилось поведение, обновите `docs/requirements.md` (и `docs/decisions.md`, если это новое решение) в том же коммите.
5. Коммитьте вместе с пересобранным `index.html`. После `git push` сайт обновляется за 1–2 минуты.
6. Распознавание на настоящем пианино автотесты не проверяют. Попросите пользователя пройти чек-лист из `docs/testing.md` и прислать цифры калибровки.

## Инварианты — не ломать

- **Генератор не ставит одну клавишу дважды подряд** (`pickNote`, в том числе на стыке строк и при перестройке строки через `row.prev`). На этом держится защита от отголосков в `handleInput`: удар с микрофона той же ноты, что засчитана меньше 1,5 с назад, не считается ошибкой. Для экранной клавиатуры и MIDI правило не действует.
- **Ошибку с микрофона засчитываем только при уверенном ударе** (`strong`) и никогда — по легато. Верную ноту принимаем по любому пути. См. `docs/decisions.md`, ADR-04.
- **Шумовой фон считается только по немузыкальным кадрам** (`ap > 0.3`, больше 1,2 с после удара). Иначе он подстраивается под пианино и связная игра теряет ноты. Проверяет тест «мелодия без педали».
- **Во время калибровки** ноты с микрофона не доходят до проверки. **После первой ноты по MIDI** (`midiSeen`) — тоже, пока устройство подключено. При подключении MIDI микрофон выключается.
- **`AudioContext` создаётся по нажатию пользователя** (требование iOS). Микрофон запрашивается без `echoCancellation`, `noiseSuppression` и `autoGainControl`.
- **Микрофон и MIDI работают только по https или на localhost.** Во встроенных фреймах (артефакт Claude) микрофон запрещён — должно оставаться понятное сообщение.
- **`localStorage` — только через `store.get/set`** (там `try/catch`). Если меняете формат, поднимайте версию ключа `slista.*.v1` и добавляйте перенос данных.
- **`index.html` — один файл без зависимостей во время работы**, кроме Google Fonts с запасными системными шрифтами. Не добавляйте CDN-библиотеки.

## Стиль

- Интерфейс и комментарии — на русском: десятичная запятая, «ё», «дБ» через неразрывный пробел. Имена в коде — английские.
- Тексты в интерфейсе пишутся с точки зрения пользователя, коротко, без жаргона. Ошибка объясняет, что сделать.
- Цвета — только через CSS-токены в `:root`. Меняя палитру, обновляйте обе тёмные ветки: `@media (prefers-color-scheme: dark)` и `:root[data-theme="dark"]`.
- Чистый JS без фреймворков. `el.hidden` вместо `style.display`. Нажатия ≥ 44 px. Анимации учитывают `prefers-reduced-motion`.
- Нотация по правилам: штили, добавочные линейки, знаки альтерации действуют до конца такта (4 ноты), бекар при отмене.

## Полезно знать

- Ступень ноты `d = октава·7 + буква` (до = 0); до¹ = C4 = `d 28` = MIDI 60. Нижняя линия: у скрипичного ключа `d 30` (E4), у басового `d 18` (G2).
- У пользователя цифровое пианино Roland FP-30 (USB и Bluetooth MIDI) и телефон на пюпитре. На iOS MIDI в браузере недоступен.
