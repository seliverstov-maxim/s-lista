# Звук рояля

Записи рояля для «С листа» — фрагменты **Salamander Grand Piano V3**, автор записи — Alexander Holm.
Источник: https://archive.org/details/SalamanderGrandPianoV3 (архив `SalamanderGrandPianoV3_OggVorbis.tar.bz2`).
Лицензия: [Creative Commons Attribution 3.0 Unported](https://creativecommons.org/licenses/by/3.0/).

Что изменено по сравнению с оригиналом (`scripts/make-piano.mjs`):
- взяты 25 нот C1–C7 через малую терцию (C, D♯, F♯, A), слой громкости 10 из 16;
- из стереозаписи оставлен один канал — правый микрофон;
- начало обрезано до удара, длина 3 с в басу и до 1,5 с вверху, в конце — затухание;
- громкость выровнена, файлы пережаты в MP3 моно 64 кбит/с.

Остальные ноты приложение играет ближайшей записью на полтона выше или ниже.
