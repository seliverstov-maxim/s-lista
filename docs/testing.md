# Тестирование

## Автоматические тесты

| Команда | Что проверяет | Время |
|---|---|---|
| `npm test` | Распознавание звука на синтезированном фортепиано: 61 клавиша на 48 и 44,1 кГц, мелодии с педалью и без, тишина, щелчки, шумный микрофон | ~12 с |
| `npm run test:e2e` | Chromium: страница без ошибок, стан нарисован (в том числе большой), экранная клавиатура, MIDI с заглушкой, включение микрофона и калибровка с искусственным микрофоном (WAV) | ~20–40 с |

Перед e2e: `npm install && npx playwright install chromium && npm run build`. Скриншоты сохраняются в `tests/e2e/out/`.

**Синтез** (`tests/helpers/synth.mjs`):
- негармоничные обертоны: `f_k = k·f0·√(1 + B·k²)`;
- слабая основная частота у басов;
- экспоненциальное затухание, верхние обертоны затухают быстрее;
- шумовой удар молоточка 20 мс;
- белый шум и сетевой фон 50 Гц.

Генератор случайных чисел с зерном, поэтому результаты воспроизводимы.

**Правила:**
- любая правка `src/detector.js` должна проходить `npm test`;
- ослаблять проверки в тестах, чтобы «позеленеть», нельзя. Если поведение меняется намеренно, обновите тест и требование в [requirements.md](requirements.md) в одном коммите.

## Ручная проверка на устройстве

Нужен телефон на пюпитре и настоящее пианино. Проходите чек-лист после изменений в распознавании, калибровке или вёрстке.

1. **Открытие.** Сайт открывается по https, нет горизонтальной прокрутки, светлая и тёмная темы читаются.
2. **Микрофон.** «Включить микрофон» → разрешить → сама открывается «Настройка микрофона».
3. **Калибровка.** Тишина 3 с → 5 нот → цифры правдоподобны: шум −70…−45 дБ, ноты −40…−10 дБ, порог между ними. Сохранить.
4. **Тишина.** 30 с тишины и тихого разговора в стороне: ни одной ошибки, «Слышу» не мигает нотами.
5. **Верные ноты.** Сыграть 3 строки верно: каждая нота засчитывается с первого удара, задержка не заметна.
6. **Повторы и легато.** Одинаковые ноты подряд в разных строках, связная игра: всё засчитывается.
7. **Неверные ноты.** Сыграть соседнюю клавишу: появляется красная нота-призрак на месте сыгранной, сообщение «Сыграно …».
8. **Басы.** Уровень «Басовый ключ»: ноты фа большой – до¹ распознаются, нет ошибок на октаву.
9. **Верх.** Диапазон до третьей октавы: высокие ноты распознаются.
10. **Педаль.** Сыграть с педалью: возможны пропуски, ложных ошибок быть не должно.
11. **MIDI** (Android/компьютер, Chrome): подключить цифровое пианино USB-кабелем → «Подключить MIDI-клавиатуру» → ноты засчитываются, микрофон выключился.
12. **Экран.** Пока включён микрофон, экран не гаснет.
13. **«Домой».** Добавить на экран «Домой»: иконка со скрипичным ключом, открывается без адресной строки (iOS).

Записывайте устройство, браузер, пианино и цифры калибровки: это пригодится для настройки детектора.
