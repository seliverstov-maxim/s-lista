# Тестирование

## Автоматические тесты

| Команда | Что проверяет | Время |
|---|---|---|
| `npm test` | Распознавание звука на синтезированном фортепиано: 61 клавиша C2–C7 и басовый ключ с тремя линейками A1–G4 на 48 и 44,1 кГц, мелодии с педалью и без, тишина, щелчки, шумный микрофон (`detector.test.mjs`). Диапазон по линейкам, генератор, перенос настроек, отголоски, партитура, раскладка по строкам, отрисовка без `NaN` (`music.test.mjs`). Инструмент загрузки пьес: каждая проверка, сдвиги октав, знаки, группировка, `.mxl`, запуск целиком, образцы в `pieces/` (`pieces.test.mjs`) | ~20 с |
| `npm run test:e2e` | Chromium: главный экран и первый запуск, настройка случайных нот и образец диапазона, диапазон 0 и 0 без линеек, «Назад» по истории и «Продолжить», перенос настроек версии 1, пьеса целиком с ошибкой, итог, «Ещё раз», «К списку», перезагрузка на тренажёре, MIDI с заглушкой, калибровка с искусственным микрофоном (WAV), открытие с диска, раскладка длинных тактов на подставленной пьесе, 360 px и альбомная ориентация без горизонтальной прокрутки, тёмная тема | ~1–2 мин |

Перед e2e: `npm install && npx playwright install chromium && npm run build`. Скриншоты сохраняются в `tests/e2e/out/` — после изменений в нотном движке или вёрстке их нужно посмотреть глазами.

**Синтез** (`tests/helpers/synth.mjs`):
- негармоничные обертоны: `f_k = k·f0·√(1 + B·k²)`;
- слабая основная частота у басов;
- экспоненциальное затухание, верхние обертоны затухают быстрее;
- шумовой удар молоточка 20 мс;
- белый шум и сетевой фон 50 Гц.

Генератор случайных чисел с зерном, поэтому результаты воспроизводимы.

**Правила:**
- любая правка `src/detector.js` должна проходить `npm test`;
- ослаблять проверки в тестах, чтобы «позеленеть», нельзя. Если поведение меняется намеренно, обновите тест и требование в [requirements.md](requirements.md) в одном коммите;
- после изменения формата данных пьесы — `npm run add-piece -- --rebuild` и `npm test`.

## Ручная проверка на устройстве

Нужен телефон на пюпитре и настоящее пианино. Проходите чек-лист после изменений в распознавании, калибровке, нотном движке или вёрстке.

1. **Открытие.** Сайт открывается по https на главном экране, нет горизонтальной прокрутки, светлая и тёмная темы читаются.
2. **Навигация.** «Случайные ноты» → «Начать» → системная «Назад» (Android) возвращает к настройке, ещё раз — на главный экран; «Продолжить» открывает тренажёр. Открытая панель закрывается кнопкой «Назад».
3. **Микрофон.** В тренажёре «Включить микрофон» → разрешить → сама открывается «Настройка микрофона».
4. **Калибровка.** Тишина 3 с → 5 нот → цифры правдоподобны: шум −70…−45 дБ, ноты −40…−10 дБ, порог между ними. Сохранить.
5. **Тишина.** 30 с тишины и тихого разговора в стороне: ни одной ошибки, «Слышу» не мигает нотами.
6. **Верные ноты.** Сыграть 3 строки верно: каждая нота засчитывается с первого удара, задержка не заметна.
7. **Неверные ноты.** Сыграть соседнюю клавишу: появляется красная нота-призрак на месте сыгранной, сообщение «Сыграно …».
8. **Басы.** Басовый ключ, 3 линейки снизу: ноты Ля₁, Си₁, До распознаются, нет ошибок на октаву.
9. **Верх.** Скрипичный ключ, 3 линейки сверху: ноты до ми³ распознаются.
10. **Пьеса с повторами.** «Братец Яков» или «Twinkle, Twinkle»: каждая повторённая нота засчитывается своим ударом, курсор не убегает вперёд сам. Если убегает — записать, через сколько после удара (подбор 250 мс, FR-PC-07).
11. **Прослушивание.** В пьесе «▶»: звук слышно из динамика, в том числе при включённом микрофоне; подсветка идёт вместе со звуком; пока звучит, игра на пианино не засчитывается; «■» останавливает. На iPhone проверить беззвучный режим и громкость при включённом микрофоне.
12. **Пьеса целиком.** «Ода к радости» в басовом ключе до конца: строки сменяются, итог показывает число нот и время, «Ещё раз» и «К списку» работают.
13. **Педаль.** Сыграть с педалью: возможны пропуски, ложных ошибок быть не должно.
14. **MIDI** (Android/компьютер, Chrome): подключить цифровое пианино USB-кабелем → «Подключить MIDI-клавиатуру» в настройках → ноты засчитываются, микрофон выключился.
15. **Экран.** Пока включён микрофон, экран не гаснет.
16. **«Домой».** Добавить на экран «Домой»: иконка со скрипичным ключом, открывается без адресной строки (iOS), навигация работает кнопками приложения.

Записывайте устройство, браузер, пианино и цифры калибровки: это пригодится для настройки детектора.
