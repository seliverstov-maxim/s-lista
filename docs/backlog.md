# Состояние и бэклог

## Состояние на 26 сентября 2026

**Сделано** (версия 2.0, [spec-2.0.md](spec-2.0.md); сайт — https://seliverstov-maxim.github.io/s-lista/, последний коммит — `git log`):
- главный экран (без «Продолжить»), два режима: случайные ноты — упражнения по 32 ноты с итогом — и пьесы;
- случайные ноты: ключ — рука, диапазон — добавочные линейки снизу и сверху;
- пьесы для одной руки в скрипичном и басовом ключе: собственный нотный движок (длительности, паузы, рёбра, ключевые знаки, размер, лиги, перенос такта), итог в конце;
- инструмент `npm run add-piece` — проверка MusicXML и LilyPond и загрузка пьес; 16 пьес: четыре наших образца и 12 из открытых источников (Википедия, Викисклад, Mutopia) — у каждой в `pieces/src/*.ly` ссылка на правку и лицензия;
- ввод через микрофон, MIDI и экранную клавиатуру; калибровка микрофона и защита от ложных ошибок;
- звук клавиш и прослушивания — записи рояля Salamander Grand Piano (CC BY 3.0), 447 КБ отдельными файлами;
- работа без интернета: при первом открытии сохраняется всё — страница, пьесы, звуки рояля;
- звёзды за каждую сыгранную пьесу: ★ — ноты без ошибок, ★★ и ★★★ — ритм (отклонение промежутков до 40 и 20 %); лучший результат — в списке пьес; метроном — кнопка-ориентир на листе.

**Проверено:**
- распознавание на синтезированном звуке: 61 клавиша C2–C7 и басовый ключ A1–G4, мелодии, шум, педаль (`npm test`);
- музыкальная логика, раскладка и отрисовка всех образцов на ширинах от 260 до 800 единиц, инструмент загрузки пьес (`npm test`);
- все экраны, навигация, пьеса целиком, MIDI с заглушкой, калибровка с искусственным микрофоном, открытие с диска, звук рояля, 360 px, тёмная тема (`npm run test:e2e`).

**Не проверено:**
- на реальном пианино и телефоне почти ничего, кроме того, что пользователь открыл сайт версии 1;
- что калибровка убрала срабатывания в тишине, на телефоне пользователя. Если нет — попросите цифры с экрана калибровки: шум, самая тихая нота, порог;
- повторы нот в пьесах с микрофона: правило «уверенный удар не раньше 250 мс» (FR-PC-07) выбрано без записей пианино;
- низкие ноты Ля₁ и Си₁ на настоящем пианино.

## Ближайшие задачи

1. **Настоящие пьесы.** Подобрать мелодии для одной руки под свободной лицензией (например, OpenScore — CC0) или набрать в MuseScore и добавить через `npm run add-piece`. Образцы сейчас — четыре простые песни.
2. **Записи настоящего пианино в тесты.** Записать на телефон по 1–2 с каждой клавиши, короткую мелодию с повторами нот, тишину и разговор. Сохранить в `tests/fixtures/*.wav` и прогонять детектор по ним так же, как по синтезу. Это главный способ узнать реальную точность и подобрать 250 мс для повторов.
3. **Отладочная панель.** Скрытый режим (например, по `#debug`) с графиком уровня, порога и фона, последними событиями `note` (`via`, `strong`) и апериодичностью YIN. Поможет разбирать жалобы вроде «ловит шум».
4. **Установка как приложения.** Работа без интернета уже есть (`sw.js`, FR-UI-05); осталось `manifest.webmanifest` с иконками 192 и 512 — тогда Android и Chrome на компьютере предложат «Установить приложение». Шрифты сохраняются со второго открытия — можно сохранять и при первом.
5. **Разнести `app.html` на модули.** Музыкальная логика и нотный движок уже в `src/music.js`; остались экраны, проверка ответа, микрофон и калибровка — они проверяются только e2e.
6. **CI.** GitHub Actions: `npm test` и `npm run test:e2e` на каждый push, проверка, что `index.html` совпадает с результатом `npm run build`.

## Идеи на потом

- Триоли, форшлаги, знаки повтора и вольты, дубль-знаки в пьесах (сейчас инструмент их отклоняет).
- Ритм под метроном: не только высота, но и попадание в долю.
- Диезы и бемоли в случайных нотах, случайные ноты в тональности.
- Большой стан: пьесы для двух рук по очереди.
- Аккорды и интервалы. Микрофон для этого не годится, нужно MIDI.
- Режим «бегущая строка»: ноты едут, а не сменяются страницей. Пьеса целиком с прокруткой.
- Продолжение пьесы с места остановки.
- Экспорт и импорт статистики, график прогресса по дням.
- Учёт времени реакции по тактам, а не только по нотам.
- Детектор в AudioWorklet или Web Worker, чтобы не зависеть от частоты кадров и фоновых вкладок.
- Профиль калибровки на каждое устройство и пианино.
- Английский интерфейс.
